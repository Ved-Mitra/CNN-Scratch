# Dataset File Paths

This file tracks the relative paths for the datasets available in the workspace.

## MNIST
- **Train Images:** `dataset/MNIST/train-images.idx3-ubyte`
- **Train Labels:** `dataset/MNIST/train-labels.idx1-ubyte`
- **Test Images:** `dataset/MNIST/t10k-images.idx3-ubyte`
- **Test Labels:** `dataset/MNIST/t10k-labels.idx1-ubyte`
- **Classes:** 10

## Fashion-MNIST
- **Train Images:** `dataset/FashionMNIST/train-images.idx3-ubyte`
- **Train Labels:** `dataset/FashionMNIST/train-labels.idx1-ubyte`
- **Test Images:** `dataset/FashionMNIST/t10k-images.idx3-ubyte`
- **Test Labels:** `dataset/FashionMNIST/t10k-labels.idx1-ubyte`
- **Classes:** 10

## EMNIST (Balanced)
- **Train Images:** `dataset/EMNIST/emnist-balanced-train-images-idx3-ubyte`
- **Train Labels:** `dataset/EMNIST/emnist-balanced-train-labels-idx1-ubyte`
- **Test Images:** `dataset/EMNIST/emnist-balanced-test-images-idx3-ubyte`
- **Test Labels:** `dataset/EMINST/emnist-balanced-test-labels-idx1-ubyte`

## CIFAR-10
- **Format:** Binary
- **Train Data (Batch 1):** `dataset/CIFAR_10/data_batch_1.bin`
- **Test Data:** `dataset/CIFAR_10/test_batch.bin`
- **Classes:** 10
- **Image Size:** 32x32x3 (RGB)
